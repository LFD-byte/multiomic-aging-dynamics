# Phenome-wide associations of nonlinear multi-omics aging trajectories and clocks

Analysis code for the manuscript *"Phenome-wide associations of nonlinear multi-omics aging trajectories and clocks"* (Li, Xue, Li, Zhuang, Ge, Zhang, Segal and Razzak).

The study analyses 10,019 adults aged 40–70 years from the Human Phenotype Project (HPP), with transcriptomic, metabolomic, lipidomic, gut-microbiome and oral-microbiome profiles and 856 phenotypes across 12 body systems. The code covers:

- cross-validated partial least-squares (PLS) analysis of age in each omics layer;
- differential expression sliding-window analysis (DE-SWAN) and functional enrichment of transition crests;
- GAM-based trajectory clustering of age-associated features and trajectory–phenotype associations;
- linear and nonlinear single-omics aging clocks, a stacked multi-omics clock and age acceleration (AgeAccel);
- associations of AgeAccel with prevalent disease and continuous phenotypes.

> **Data access.** Participant-level HPP data are available under restricted access and are **not** included in this repository. See [Data availability](#data-availability). A synthetic dataset for testing the code is generated by the demo below.

│   ├── Result-02/         DE-SWAN, crest enrichment, LION, oral pathways, crest–phenotype tests -> Figs. 2, 3; Supp. Fig. 1, 2

│   └── Result-05/         AgeAccel associations with disease and phenotypes                     -> Fig. 6c,d; Supp. Figs. 4, 5

Within each directory, scripts are numbered in execution order. Each `02-papers/Result-0*/` directory contains a `00-manuscript_stats.py` script that compiles the summary statistics reported in the manuscript.

## 1. System requirements

### Operating system and hardware

- The code runs on Linux, macOS and Windows. Analyses were developed and run on Windows 11 and Linux; the demo has been tested on Linux.
- No non-standard hardware is required. The demo runs on a normal desktop computer. The full analyses (for example 999-permutation PLS tests and repeated nested cross-validation on 17,346 transcripts) benefit from a multi-core workstation.

## 2. Installation guide

### Python

```bash
git clone https://github.com/LFD-byte/multiomic-aging-dynamics.git
cd multiomic-aging-dynamics

# Option A: conda
conda create -n aging python=3.11 -y
conda activate aging
pip install -r requirements.txt

# Option B: venv
python3.11 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Run all commands from the repository root. The preprocessing notebooks import the shared `phenokit` package; add the repository root to `PYTHONPATH` (or edit the `sys.path.append(...)` line at the top of each notebook to point to your local copy).

### R

```r
install.packages(c("remotes", "BiocManager"))
BiocManager::install(version = "3.12")
BiocManager::install(c("clusterProfiler", "org.Hs.eg.db", "GOSemSim", "AnnotationDbi", "GO.db"))
install.packages(c("car", "data.table", "imputeLCMD", "igraph", "dplyr", "ggplot2",
                   "mgcv", "patchwork", "ragg", "svglite", "scales", "gtable",
                   "jsonlite", "stringr", "tidyr"))
remotes::install_github("lehallier/DEswan")
```

To match the versions above exactly, install specific CRAN versions with `remotes::install_version("<package>", version = "<version>")`.

### Typical install time

About 5–10 minutes for the Python environment and 20–30 minutes for the R and Bioconductor packages on a normal desktop computer with a broadband connection.

## 3. Demo

The demo generates a small synthetic multi-omics dataset (300–500 simulated participants per layer, 30–200 features per layer, about 10% with a repeated visit and 30% of features with linear, accelerating or midlife-peak age effects) and runs the leakage-free cross-validated PLS age analysis used for Fig. 1d.

### Instructions

From the repository root:

```bash
# 1. Generate synthetic data (writes demo/data/omics_data/*_with_metadata.parquet)
python demo/make_demo_data.py

# 2. Optional: built-in unit checks (PLS equivalence, no train/test leakage, permutation refit, FDR)
python 02-papers/Result-01/02-omics_pca_leakage_free_cv.py --self-test

# 3. Run the PLS age analysis on the synthetic data
python 02-papers/Result-01/02-omics_pca_leakage_free_cv.py \
    --data-dir demo/data/omics_data \
    --output-dir demo/outputs \
    --figure-dir demo/outputs \
    --delivery-pdf demo/outputs/demo_pls_age.pdf \
    --n-permutations 99 --n-bootstrap 200 --suffix demo
```

### Expected output

Step 2 prints `Self-test passed: PLS1 equivalence, leakage boundary, refit, and FDR checks.`

Step 3 prints, for each layer, the number of participants and features, fold-wise progress and the cross-validated Spearman correlation between the out-of-fold PLS score and age, followed by a summary table. With the default seed the results are approximately:

| Layer | Participants | Features | ρ<sub>CV</sub> | Permutation *P* |
|---|---|---|---|---|
| Transcriptomics | 400 | 200 | 0.89 | 0.01 |
| Metabolomics | 300 | 50 | 0.77 | 0.01 |
| Lipidomics | 400 | 40 | 0.56 | 0.01 |
| Gut microbiome | 500 | 60 | 0.57 | 0.01 |
| Oral microbiome | 500 | 30 | 0.34 | 0.01 |

(*P* = 0.01 is the minimum attainable with 99 permutations. Small numerical differences can occur across package versions.)

The following files are written to `demo/outputs/`:

- `multi_omics_pls_age_spearman_demo.{pdf,svg,png}` and `demo_pls_age.pdf`: five-layer figure in the style of Fig. 1d;
- `multi_omics_pls_age_demo_summary.csv`: per-layer statistics (ρ<sub>CV</sub>, bootstrap 95% CI, permutation *P*, BH-adjusted *q*, Q²<sub>CV</sub>);
- `multi_omics_pls_age_demo_oof_scores.parquet` and `multi_omics_pls_age_demo_permutation_null.parquet`: participant-level out-of-fold scores and the permutation null;
- `multi_omics_pls_age_demo_metadata.json`: run parameters and file paths.

### Expected run time

Less than 1 minute on a normal desktop computer (about 5 s in our test).

## 4. Instructions for use

### Obtaining the data

Request access to HPP data through the [Human Phenotype Project data access portal](https://humanphenotypeproject.org/data-access) (contact info@pheno.ai for instructions). Place the HPP dataset files in `01-preprocessing/raw_data/`. All data directories are excluded from version control by `.gitignore`.

### Running the analyses

Run the steps in this order; within each directory, run scripts in numerical order.

1. **Preprocessing** — `01-preprocessing/000-population.ipynb` to `070-oral_microbiome.ipynb`. These notebooks define the cohort, compute decimal age, clean phenotypes for the 12 body systems and perform omics quality control, normalization, batch correction and imputation. The analysis-ready tables are written to `02-papers/01-interim_data/omics_data/` (one `<layer>_with_metadata.parquet` file per omics layer, with `participant_id`, `age`, `sex` and feature columns) and `02-papers/01-interim_data/systems_data/`.
2. **Result-01** (Fig. 1) — `01-cohort_feature.ipynb`, `02-omics_pca_leakage_free_cv.py` (run without `--data-dir` to use the default data location and the full 999 permutations), `03-age_trend.ipynb`, `03-age_trend_heatmap.R`.
3. **Result-02** (Figs. 2, 3) — `01-de_swan_omics_one.R` and window-sensitivity scripts, transcriptomic crest enrichment (`02-*.R`), LION analysis (`03_*`), oral pathway profiles (`04-*`) and crest–phenotype associations (`05-*`). Scripts `06`–`11` (with `*.sh` runners) contain additional robustness and sex-stratified analyses.
4. **Result-03** (Figs. 4, 5) — `01-molecule_clustering.py`, cluster enrichment (`02-*`, `03-*`), oral MetaCyc analyses (`04-*`), crest–cluster overlap (`05-*`) and cluster–phenotype associations (`11-*`, `12-*`).
5. **Result-04** (Fig. 6a,b) — `01-nonlinearity_model_comparison.py` (single-omics clocks) and `02-aging_clock.py` (stacked multi-omics clock and AgeAccel).
6. **Result-05** (Fig. 6c,d) — `disease_odds_ratio.py` / `01-disease_odds_ratio.ipynb` and `dose_response_forest.py` / `02-dose_response_forest.ipynb`.
7. **Manuscript statistics** — `python 02-papers/Result-0X/00-manuscript_stats.py` in each directory.

Most Python scripts accept `--help` for their command-line options.

### Reproducibility

Stochastic steps (cross-validation splits, permutations, bootstrap resampling and model fitting) use fixed random seeds, set to 42 unless otherwise specified in the code. All splits and resamples are drawn at the participant level. Software versions are listed above and in Supplementary Note 1 of the manuscript.
